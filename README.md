# Brio — releases

Notarized downloads for **Brio**, a macOS menu-bar developer toolbox.

This repository holds **release artefacts only** — no source. Grab the latest
`.dmg` from [Releases](https://github.com/DavidNorrisDev/brio-releases/releases),
open it, and drag Brio to Applications.

Brio updates itself from here via [Sparkle](https://sparkle-project.org). To
receive pre-release builds, turn on **Include beta releases** in Brio's Settings;
releases marked *pre-release* below are the ones that reaches you.

Requires macOS 26 or later.
